# TCL Ion V T607DL (`boratf`)

LineageOS 24 (Android 17) device tree for the TCL Ion V T607DL, MediaTek
MT6765 (Helio P35), A-only, dynamic partitions.

## Hardware / firmware notes

- Stock firmware: UHBG (`TCL/T607DL/Bora_TF:13/TP1A.220624.014/UHBG`).
- `ro.hardware` / `ro.boot.hardware` is `mt6762`; the platform is `mt6765`.
  Everything platform-named (`fstab`, `init.recovery`, ...) is installed under
  both names.
- Stock `super` layout (8192 MiB, one group `main`):

  | partition | stock size | this tree |
  |-----------|-----------:|-----------|
  | system    | 3035 MiB   | built     |
  | product   | 2259 MiB   | built     |
  | vendor    |  625 MiB   | built (stock blobs + rebuilt HALs) |
  | odm       |   10 MiB   | built (props + SKU vintf manifest) |
  | oem       | 1052 MiB   | not shipped (stock fstab entry marked `nofail`) |
  | preload   |  194 MiB   | not shipped (stock fstab entry already `nofail`) |

  There is no `system_ext` partition (fused into system).

## Blobs

`proprietary-files.txt` is generated from the stock UHBG `vendor` and `odm`
images (`/mnt/vendor`, `/mnt/odm-tmp`) and extracted to `vendor/tcl/boratf`.

- The stock vendor is largely self-contained: it ships its own copies of many
  platform libraries. The generated vendor tree therefore uses raw copy rules
  for the blobs (no Soong dependency resolution) so the vendor partition stays
  byte-identical to stock where untouched.
  `extract-files.py` therefore runs with `check_elf=False`.
- Rebuilt from source (their stock single-purpose binaries are excluded):
  audio, Bluetooth (AIDL), DRM clearkey, gatekeeper (service; trustonic impl
  stays a blob), composer 2.1, health, memtrack, sensors (AIDL multihal + HIDL
  2.0 subhal), thermal, USB, USB gadget, vibrator, lights, power
  (lineage-libperfmgr + MTK mtkpower stub), MTK FPSGo/power clients.
- Stock HAL binaries kept as blobs: camera stack (incl. `cameraalgoserver`,
  `camerahalserver`), radio/RILD + MTK radio extensions, GNSS, Wi-Fi
  (hostapd/supplicant/wlan_assistant), widevine DRM, keymaster 4.1 trustonic,
  face HAL, cas, media C2/OMX, all MTK/TCL services.
- **Megvii / Face++ blobs are intentionally not shipped** (LineageOS
  prohibited-files policy): `libMegviiUnlock.so`, `libmegface.so` and
  `megvii_model_file`. TCT face unlock will not work; everything else is
  unaffected. Re-adding them locally requires
  `extract-files.py --allow-prohibited-files` and will make the vendor tree
  unpublishable.

### Extracting

```sh
# stock partitions mounted at /mnt/vendor, /mnt/product, /mnt/odm-tmp
# (dump dir has symlinks to those mounts)
cd device/tcl/boratf
PYTHONPATH=../../../tools/extract-utils python3 extract-files.py \
    --keep-dump /tmp/opencode/boratf-dump
PYTHONPATH=../../../tools/extract-utils python3 setup-makefiles.py
```

## Kernel

`kernel/tcl/boratf` (anoraktrend/lineagemoto_boratf, `bakasu` branch),
`bora_tf_live_defconfig`, built with clang-r383902
(`TARGET_KERNEL_CLANG_PATH`, override via env). The kernel carries the TCL
bring-up work: display, charger/Type-C, in-tree WMT/WLAN/BT/FM/GPS, camera
(TCL imgsensor ioctl), accdet, USB clock recovery and the Awinic AW3641E
flashlight driver.

The `bakasu` branch also integrates the BakaSU root driver (KernelSU-based)
as a git submodule:

- the submodule lives at `KernelSU/` (anoraktrend/BakaSU, pinned by the
  branch) and is symlinked as `drivers/kernelsu`;
- run `git submodule update --init` in `kernel/tcl/boratf` after a fresh
  `repo sync`;
- `CONFIG_KSU=y` with the manual (non-GKI) hook is set in
  `bora_tf_live_defconfig`;
- the ROM ships **no `su` binary**: root is only granted when the matching
  manager APK is installed (BakaSU beta 35259 / ReSukiSU 0.13.9-rc3
  generation);
- use the `lineage-24.0` revision in `.repo/local_manifests/boratf.xml` for
  a kernel without the root driver.

Kernel modules built in-tree are installed to `/vendor/lib/modules`; the
stock `.ko` files (built for the old kernel) are excluded.

## VINTF

`manifest.xml` is derived from the stock vendor manifest (generated by
`tools/gen-manifest.py`): HALs that are rebuilt from source are dropped (their
services install their own fragments), as are stock HIDL entries with no
provider in this build — HIDL Bluetooth audio 2.1 (replaced by the AIDL
interface registered by the MTK audio HAL from
`android.hardware.bluetooth.audio-impl`), `android.hardware.media.omx` (the
OMX service is not shipped; the MTK codecs are C2) and
`vendor.mediatek.hardware.bluetooth.audio` (unused by the AOSP Bluetooth
stack). Everything else is kept. The TCL/TCT vendor HALs that no AOSP
compatibility matrix describes are declared optional in
`vintf/boratf_framework_compatibility_matrix.xml`. The stock odm SKU manifest
(`manifest_ss.xml`, single SIM) is shipped as `/odm/etc/vintf/manifest.xml`.

The kernel side of the VINTF check is disabled
(`PRODUCT_OTA_ENFORCE_VINTF_KERNEL_REQUIREMENTS := false`): this is a one-off
build with no OTA packages, and the 4.19.325 kernel does not provide the FCM 7
kernel hardening configs (`CONFIG_CFI_CLANG`, `CONFIG_SHADOW_CALL_STACK`).

## Building

```sh
source build/envsetup.sh
lunch lineage_boratf cp2a userdebug    # LineageOS 24 / Android 17
m
```

The build does **not** produce a recovery image
(`PRODUCT_BUILD_RECOVERY_IMAGE := false`); recovery is source-built TWRP in a
separate tree (`/home/lucy/media/android/twrp-12.1`).

## Flashing

Device is A-only with a 64 MiB boot/recovery. Flash with preloader fastboot
(see `T607-Lineage-build/BUILD-NOTES.md`; `adb reboot bootloader` does not
work on this unit):

```sh
fastboot flash boot    out/target/product/boratf/boot.img
fastboot flash super   out/target/product/boratf/super.img
fastboot flash vbmeta         out/target/product/boratf/vbmeta.img
fastboot flash vbmeta_system  out/target/product/boratf/vbmeta_system.img
fastboot flash vbmeta_vendor  out/target/product/boratf/vbmeta_vendor.img
```

AVB uses test keys; the vbmeta images must be flashed together with the
images they describe (dm-verity is wired through the stock fstab flags).

## Bundled apps

None. Earlier iterations staged the Immich client, an Immich cloud media
provider and Jellyfin, but ROMs here are kept app-free (stock minimal set
plus whatever is installed by the user).

## Known limitations

- Face unlock: Megvii blobs excluded (see above).
- `oem`/`preload` partitions are not shipped; their fstab entries are
  `nofail`.
- FBE/keystore: the stock trustonic keymaster/gatekeeper blobs are kept
  as-is; userdata encryption depends on them working against the new
  framework.
